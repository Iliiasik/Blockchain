# Bitcoin transactions
A Bitcoin transaction is a fundamental data structure that represents
the transfer of value between participants in the blockchain network. 
Transactions are grouped into blocks and form the backbone of the decentralized 
ledger, ensuring ownership and preventing double-spending.

## Structure of a transaction
A transaction consists of three main components:
- **Transaction ID (TXID)** — a unique identifier generated by hashing the serialized transaction
- **Inputs (Vin)** — references to unspent outputs (UTXOs) from previous transactions
- **Outputs (Vout)** — new UTXOs that define the destination addresses and the transferred value
Additional metadata may include fees and signatures to guarantee security and network acceptance.
---
## Coinbase transactions
The first transaction in every block is the **coinbase transaction**:
- Has no inputs (creates new coins)
- Serves as miner reward
- Combines block subsidy with transaction fees
---
## Transaction lifecycle
1. **Input selection**  
   References spendable UTXOs
2. **Signing**  
   Private key generates digital signature
3. **Broadcasting**  
   Sent to P2P network
4. **Validation**  
   Nodes verify signatures and rules
5. **Block inclusion**  
   Miners add to block via Proof-of-Work
---
## Transaction fees
Calculated as:  
`Fee = Sum(inputs) - Sum(outputs)`
Purpose:
- Miner incentive
- Network spam prevention
- Higher fees = faster confirmation
---
## Digital signatures
Uses **ECDSA** algorithm:
- Valid signature required for each input
- Proves private key ownership
- Enables verification without key exposure
- Ensures transaction immutability
---
## Summary
Bitcoin transactions enable secure value transfer through:
- UTXO-based inputs/outputs
- Cryptographic signatures
- Miner incentives via fees
- Decentralized validation
This creates a tamper-resistant system for trustless digital currency exchange.
